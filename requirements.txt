# ===========================================================================
# NOTES
# ===========================================================================
#
# 1. torch must be installed from the CUDA index, not plain PyPI:
#
#      pip install torch==2.6.0 --index-url https://download.pytorch.org/whl/cu124
#
#    (plain `pip install torch==2.6.0` gives the CPU build or a different CUDA.)
#
# 2. fair-esm / openfold  --  IMPORTANT, do not skip
#
#    fair-esm's `esm.esmfold.v1` modules import the *top-level* `openfold`
#    package. BioDynaSpec does NOT install upstream OpenFold; it vendors a copy
#    at src/openfold_local/ (see src/openfold_local/README.md).
#    The repository therefore ships `openfold.py` at its root: a lazy shim that
#    aliases `openfold.*` -> `src.openfold_local.*`. It only works when the
#    project root is on PYTHONPATH, which scripts/*.sh guarantee.
#    If you instead `pip install openfold`, that install will conflict with the
#    shim — remove openfold.py if you go that route.
#
#    src/featureextractor.py imports esm.esmfold.v1.tri_self_attn_block
#    (TriangularSelfAttentionBlock), so this path is exercised on every run.
#
# 3. protenix
#
#    Listed because several vendored modules import it. Weights are not needed
#    for the ATLAS trajectory pipeline (BioDynaSpec conditions on ESM-2 + the
#    anchor structure, not on Protenix/AlphaFold3 checkpoints).
#
# 4. gemmi is OPTIONAL
#
#    runner/data_prepare/extract_frames/save_frames_to_npy_atlas.py uses it only
#    for an optional CIF export path; the training pipeline does not need it.
#
# 5. torchdrug is NOT required (and not installed in the reference env).
#
#    It used to be a hard import in src/data/dataset_atlas.py, but it was only
#    needed by a dead code path (`collate_fn` / `data.PackedGraph`). The
#    DataModule actually uses `collate_fn_single`. That import has been removed,
#    so torchdrug is no longer needed to train.
#
# 6. Build toolchain (only if you need to compile flash-attn / DeepSpeed ops):
#
#      * CUDA toolkit 12.4 (nvcc)  -- and set CUDACXX=$CUDA_HOME/bin/nvcc
#      * GCC 13.x                   -- CUDA 12.4 rejects older GCC; this is what
#                                      dependencies.sh step 1 builds.
#      * cutlass (for DeepSpeed's optional kernels)
#
